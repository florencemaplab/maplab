# Florence MAPLab GitHub Pages site

Static multi-page site for `florencemaplab/maplab`.

## Deploy

1. Copy these files into the root of the GitHub repository.
2. Commit and push to `main`.
3. In GitHub, open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, branch `main`, folder `/root`.
5. The project site should be available at `https://florencemaplab.github.io/maplab/`.

## Files

- `index.html` — home page
- `about.html` — lab overview and research themes
- `people.html` — members and collaborators
- `facilities.html` — in-house and joint labs
- `projects.html` — ongoing projects
- `publications.html` — selected recent publication list
- `news.html` — news and events placeholder area
- `contact.html` — contact details
- `style.css` — shared styling

## Review before publishing

- Replace test news/events entries.
- Add photos only after consent.
- Verify emails, names, roles and publication details.
- Expand THE and RIGHTSTRESS pages when project abstracts are available.

Content is adapted from public MAPLab/UniFI pages and should be reviewed by the lab before use.
